# Changelog

User-visible changes are summarized here. Release drafts also include a generated
list of merged pull requests.

## [Unreleased]

### Added

- TIFF viewing (`.tif` and `.tiff`), showing the first image in multi-image files.

## [0.2.0] - 2026-10-22

### Added

- GIF viewing with automatic animation playback and Space to pause, resume, or replay.
- BMP viewing with the existing navigation and image controls.

## [0.1.0] - 2026-10-22

### Added

- A minimal dark interface for viewing JPEG, PNG, and WebP photos on Windows.
- Natural folder navigation, drag and drop, and opening images from a file path.
- Pointer-centered zoom, panning, Fit and 100% views, full screen, and view-only rotation.
- Background image loading, EXIF orientation, and reduced previews for large dimensions.
- Portable Windows packages with license notices and matching dependency sources.
