# Security Policy

## Supported versions

Security updates target the latest stable release of Lumen.

## Reporting a vulnerability

Report suspected security vulnerabilities through
[GitHub's private vulnerability reporting](https://github.com/Lightre/lumen/security/advisories/new).
Please do not disclose vulnerability details in public issues.

Include your Lumen and Windows versions, steps to reproduce, and the potential
security impact. Attach a sample image privately if it helps reproduce the issue.

For ordinary bugs and feature requests, use [GitHub Issues](https://github.com/Lightre/lumen/issues/new/choose).
